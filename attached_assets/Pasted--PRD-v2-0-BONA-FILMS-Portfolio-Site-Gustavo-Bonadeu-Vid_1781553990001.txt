## 0. RESUMO EXECUTIVO

**Cliente:** Gustavo Bonadeu — videomaker e criador de reels
**Marca:** BONA FILMS (produtora audiovisual)
**Idioma:** Português brasileiro (PT-BR)
**Tipo:** Single page portfolio (one-pager)
**Tom visual:** Editorial, artístico, preto-e-branco premium. Referências diretas: Tukiko Miku (hero/composição) + James Holt (grid editorial + micro-textos).
**Tom da copy:** Direto, frases curtas, vibe cinematográfica. Sem "pacotes", "valores", "investimento". Sem palavras como "diretor", "direção".

**Stack:** Next.js 14 + Tailwind + Framer Motion + Lenis. MP4 self-hosted.

**Estrutura final (6 seções):**
1. Hero (capa editorial com nome sobreposto à foto)
2. Marquee (faixa de transição)
3. Sobre (quem é o Gustavo)
4. Reel (vídeo destaque principal)
5. Trabalhos selecionados (grid dos 3 vídeos restantes em 16:9)
6. Processo (3 pilares — sem linguagem de venda)
7. Contato (Instagram + WhatsApp)

### 4.3 Especificação Pixel-by-Pixel

**Section container:**
```css
section.hero {
  min-height: 100vh;
  background: #F2F2EE;
  background-image: linear-gradient(to right, rgba(10,10,10,0.04) 1px, transparent 1px);
  background-size: calc((100% - 128px) / 12) 100%;
  background-position: 64px 0;
  position: relative;
  display: flex;
  flex-direction: column;
  justify-content: center;
  padding: 120px 64px 64px;
  overflow: hidden;
}
```

**Hero content wrapper (centraliza tudo):**
```css
.hero-content {
  max-width: 1440px;
  margin: 0 auto;
  width: 100%;
  position: relative;
}
```

**Título "Bona Films":**
```css
.hero-title {
  font-family: 'Inter', sans-serif;
  font-weight: 900;
  font-size: clamp(140px, 18vw, 280px);
  letter-spacing: -0.05em;
  line-height: 0.85;
  color: #0A0A0A;
  text-align: center;
  position: relative;
  z-index: 5;
  mix-blend-mode: difference;
  /* Onde o texto sobrepõe a foto preto-e-branco, ele inverte os pixels:
     - Sobre fundo claro (#F2F2EE): aparece preto
     - Sobre foto P&B: aparece "invertido" (claro vira escuro, escuro vira claro)
     Esse é O EFEITO característico do Tukiko Miku. */
  margin: 0;
  padding: 0;
}
```

**Importante:** O título é UMA LINHA SÓ ("Bona Films"). Não quebrar em duas linhas. Em telas muito pequenas (< 640px), reduzir font-size para 64px e SE necessário quebrar como "Bona / Films" em 2 linhas.

**Foto Hero:**
```css
.hero-photo {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -45%);
  /* -45% (não -50%) porque o título precisa atravessar a parte SUPERIOR da foto */
  width: 540px;
  max-width: 60%;
  aspect-ratio: 4 / 5;
  /* IMPORTANTE: aspect ratio VERTICAL (4:5), NÃO horizontal */
  object-fit: cover;
  object-position: center top;
  filter: grayscale(100%) contrast(1.1);
  z-index: 1;
  /* z-index 1 = ATRÁS do título (que tem z-index 5) */
}
```

**Por que aspect 4:5 (vertical) e não 16:10 (horizontal)?**
Porque o título precisa atravessar a foto NO MEIO. Se a foto fosse horizontal, ela ficaria muito baixa/larga e o título "passaria por cima". Com a foto vertical, o título atravessa a TESTA/OLHOS do modelo, criando o efeito icônico do Tukiko.
