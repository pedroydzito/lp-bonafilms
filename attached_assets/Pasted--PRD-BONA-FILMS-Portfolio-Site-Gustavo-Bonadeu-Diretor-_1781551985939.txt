# PRD — BONA FILMS
## Portfolio Site | Gustavo Bonadeu (Diretor/Videomaker)

> Documento de especificação para construção da landing page no Aurabuild.
> Versão 1.0 — Pronto para implementação. Não improvisar fora do escopo definido.

---

## 0. RESUMO EXECUTIVO

**Cliente:** Gustavo Bonadeu — videomaker / criador de reels
**Marca:** BONA FILMS (produtora audiovisual)
**Objetivo do site:** Portfolio digital minimalista, artístico, focado em mostrar trabalhos em vídeo e gerar contato direto via WhatsApp/Instagram.

**Tipo de página:** SINGLE PAGE PORTFOLIO (one-pager com scroll)
**Tom visual:** Editorial, artístico, preto-e-branco premium. Inspiração direta: Tukiko Miku creative agency portfolio.
**Tom da copy:** Direto, com pegada cinematográfica. Frases curtas. Nenhuma frase de venda agressiva. Nada de "pacotes", "valores", "investimento".

**Stack alvo:** Next.js + Tailwind CSS (gerado pelo Aurabuild → exportado → ajustado no Antigravity → deploy Vercel).

**Estrutura final (6 seções):**
1. Hero (capa impactante com nome + foto P&B)
2. About (quem é o Gustavo)
3. Showreel (vídeo destaque principal)
4. Selected Work (grid dos outros 3 vídeos)
5. Approach (3 pilares do trabalho dele — inspirado no mídia kit, sem pacotes)
6. Contact (Instagram + WhatsApp)

## 2. DESIGN SYSTEM

### 2.1 Paleta de Cores

```
COR                    | HEX        | USO
-----------------------|------------|--------------------------------------------
Background base        | #F2F2EE    | Fundo principal (off-white quente, NÃO branco puro)
Background alt         | #0A0A0A    | Seções escuras (Showreel, Contact)
Black absolute         | #000000    | Foto hero, blocos pretos puros, tipografia primária
Text primary           | #0A0A0A    | Texto sobre fundo claro
Text on dark           | #F2F2EE    | Texto sobre fundo escuro
Text muted             | #6B6B66    | Labels, metadados, captions
Border subtle          | #D4D4CE    | Divisores sobre fundo claro
Border subtle dark     | #1F1F1F    | Divisores sobre fundo escuro
Accent (mínimo)        | nenhum     | NÃO usar cor de destaque. Tudo é P&B + cinzas.
```

**Regra dura:** ZERO uso de cores além dos cinzas/preto/off-white. O contraste é a única ferramenta visual. Não usar gradientes coloridos, glow, shadows coloridos.

### 2.2 Tipografia

**Display (headings grandes, nome no hero):**
- Fonte: `PP Neue Montreal` (se Aurabuild não tiver, fallback para `Space Grotesk` weight 700)
- Alternativa free 100% disponível: **Inter** com `font-weight: 900` e `letter-spacing: -0.04em`
- Decisão para Aurabuild: usar **Inter** (Google Fonts) com weights 400/500/700/900

**Body (parágrafos):**
- Fonte: `Inter` weight 400
- Line-height: 1.6

**Mono (coordenadas, labels técnicos, números pequenos):**
- Fonte: `JetBrains Mono` weight 400
- Uso: coordenadas geográficas, ano dos projetos, números/stats

### 2.3 Escala Tipográfica

| Token | Desktop | Mobile | Peso | Uso |
